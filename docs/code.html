Code

Python, PyTorch, nflows  /  SLURM scripts for HPC

Each experiment is fully specified by one YAML config. The four stages run identically for every arm, whether a CNN cube compressor, an MLP summary compressor, or the no-compression baseline.

View repository

Install

git clone https://github.com/Dilru1/21cm-sbi-vmim.git
cd 21cm-sbi-vmim
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

The 3D cube renderings additionally need pyvista.

Run the pipeline

Each stage reads and writes {scratch_root}/{arm_name}/, set in the config or on the command line.

# Stage 1: train a compressor and export summaries
python stage1_compress.py configs/vmim_/arm_cnn_vmim_n1.yaml
#   or, for the no-compression baseline
python stage1_raw.py configs/baseline_/baseline_pdf.yaml

# Stage 2: fit neural likelihoods on the exported summaries
python stage2_nle.py configs/vmim_/arm_cnn_vmim_n1.yaml --models gmm,maf,nsf

# Stage 3: SBC MCMC chains on the validation set
python stage3_mcmc.py configs/vmim_/arm_cnn_vmim_n1.yaml

# Stage 4: compare arms
python stage4_eval.py --list sbc_lists/baseline.list \
    --out eval_report --dlogp 10 --filtered-only

Repository layout

sbi/
Core package: config and data loading, compressors (3D SE-ResNet, MLP, variational heads), NLE models, MCMC sampler, SBC validation.
configs/
One YAML per arm, grouped as baseline_, mlp_, mse_ and vmim_, including jitter, floor and noise-level variants.
stage1–4_*.py
Entry points for compression, likelihood fitting, sampling and evaluation.
sbc_lists/
Lists of chain directories that stage 4 overplots and scores.
slurm/
Batch scripts for each stage on a SLURM cluster.
tools/
Standalone plotting and diagnostic scripts, including the figures on this site.

Data

The pipeline expects the LORELI II cubes, summary tables and SKA noise bank described by Meriot & Semelin (2024) and Semelin et al. (2025). They are not distributed with the repository.
